# Security Policy

Please do not disclose vulnerabilities in public issues.

Report suspected security issues privately to the repository maintainers through GitHub's security advisory feature. Include affected versions, reproduction steps, expected impact, and any safe proof of concept.

StellarGuard is an early-stage policy evaluator. It does not replace transaction simulation, wallet confirmation, independent code review, or application-specific security controls. Do not rely on it as the sole protection for funds.
